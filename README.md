# IEOR 142A Midterm Review

A written study guide for the IEOR 142A (Intro to Machine Learning and Data Analytics) midterm. Everything is built from the Spring 2021 practice midterms 1 to 3.

## Study guide

[`STUDY_GUIDE.md`](STUDY_GUIDE.md) has every concept the practice midterms test, worked exam questions, new practice problems with answers, all 43 multiple-choice answers with reasons, and a note-sheet blueprint.

## Source

The exam questions, datasets and R output quoted in the study guide come from the IEOR 142 (UC Berkeley) Spring 2021 practice midterms.
